# OpenLumara webui themes

The .json files are the themes (they are basically just color schemes). You can add CSS files with the same name as the json (so like sakura.json + sakura.css) files in order to apply custom CSS

## Format

```json
{
  "dark":  { "--bg-primary": "#0a0712", "--accent": "#b388ff" },
  "light": { "--bg-primary": "#f7f3fc", "--accent": "#7c4dcc" }
}
```
